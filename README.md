# LC-3 虚拟机与 CPU 模拟器 (C 语言实现)

一个使用纯 C 语言实现的 16 位 **LC-3 (Little Computer 3)** 虚拟机与硬件模拟器。该项目完整模拟了物理 CPU 的核心执行周期（取指、译码、执行），支持全套 16 种机器指令、内存映射 I/O 中断以及二进制程序镜像加载，可在终端无依赖运行 2048 等经典汇编游戏。

---

## ? 核心特性与技术亮点

- **硬件级建模**：
  - 模拟了 128KB 物理寻址内存（65,536 个 16-bit 内存单元）。
  - 实现了 8 个通用寄存器（R0~R7）、程序计数器（PC）与条件状态寄存器（COND）。
- **指令系统（ISA）完备**：
  - **算术逻辑单元 (ALU)**：支持 `ADD`、`AND`、`NOT` 等算术运算，支持立即数与寄存器两种寻址模式。
  - **内存数据流转**：实现相对寻址（`LD`/`ST`）、基址偏移（`LDR`/`STR`）、间接寻址（`LDI`/`STI`，模拟二级指针）及有效地址加载（`LEA`）。
  - **分支与控制流**：实现条件分支跳转（`BR`，基于 P/Z/N 状态标志位）、无条件跳转（`JMP`）及子程序调用（`JSR`，模拟函数调用与栈回溯）。
- **系统调用与外设交互 (TRAP & I/O)**：
  - 实现内存映射 I/O（Memory-Mapped I/O）：通过监听 `0xFE00` 与 `0xFE02` 映射键盘输入。
  - 支持常用 TRAP 陷阱例程（`GETC`, `OUT`, `PUTS`, `IN`, `HALT`）。
- **底层工程细节处理**：
  - **大小端字节序转换**：实现二进制文件的端序翻转（Big-Endian 转本机 Little-Endian）。
  - **跨平台终端兼容**：针对 Windows (`conio.h`) 与 Linux (`termios`) 做了终端无缓冲输入的适配。
